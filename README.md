# 올해 첫 곡은 뭐양? · 복주머니 레코드

도트풍 게임처럼 진행되는 새해 음악 이벤트입니다. 밤 초원에 귀여운 양 110마리가 풀을 뜯고, 화면 가운데 어두운 반투명 창에 “올 한 해 정말 고생 많았어요” 같은 격려 한마디가 무작위로 뜨고 이야기가 이어집니다. 양떼 사이에 헤드폰을 낀 붉은 양이 숨어 있어서, PC에서는 클릭·휴대폰에서는 탭으로 찾아 누르면 전구가 뜨며 “띠링!” 소리가 나고 붉은 양이 언덕 위로 달려갑니다. 붉은 양 뒤로 붉은 해가 떠오르면 “올해 첫 곡은 뭐양?”이 나타나고, 이름을 알려 준 뒤 내년에 가장 바라는 1순위 소망을 고르면 복주머니가 열려 그 소망에 어울리는 곡과 덕담이 나옵니다. 공식 YouTube 영상으로 듣거나 이름과 소망이 들어간 900×1100 티켓 PNG를 저장할 수 있습니다.

Next.js App Router · React · TypeScript(strict) · styled-components · Canvas 2D · Web Audio. DB, 회원가입, API 키, 음원 파일이 필요 없습니다.

## 진행 순서

0. **나레이션 → 초원** — 화면 가운데 어두운 반투명 모달(PROLOGUE)에서 텍스트 게임처럼 한 줄씩 타이핑되는 나레이션(무작위 격려 한마디 → 양들이 준비한 새해 선물 → 선물을 든 붉은 양이 양떼 속에 숨었다 → 헤드폰 낀 붉은 양을 찾아 달라)을 화면 클릭/탭 또는 Enter·Space로 넘깁니다. 끝나면 아래에 작은 안내만 남고, 붉은 양을 클릭/탭하면 시작합니다. 흰 양을 누르면 깡충 뛰고, 6초 동안 못 찾으면 붉은 양이 깡충거리며 힌트를 줍니다. `못 찾겠어요`(또는 Enter·Space)로 바로 찾을 수도 있습니다. 브라우저는 사용자가 한 번 눌러야 소리를 낼 수 있어서 이 첫 클릭이 효과음을 켭니다. 상단 `♪ ON/OFF`로 효과음을 끄고 켤 수 있고 이 브라우저에 기억됩니다.
1. **발견 이후 (약 5.8초)** — 전구 + “띠링!” → 붉은 양이 양떼를 빠져나와 언덕으로 달려감(카메라가 따라감) → 반짝 연기와 함께 큰 모습으로 → 줌인, 뒤에서 붉은 해가 뜸 → 제목 → 대화창. 화면 클릭, `건너뛰기`, Enter·Space·Esc로 건너뜁니다. 해는 언덕 뒤로 반쯤 걸린 따뜻한 그라데이션이며 햇살 줄무늬는 일부러 넣지 않았습니다. 모션 감소 설정이면 0.3초 뒤 바로 대화창으로 갑니다.
2. **이름** — 붉은 양이 말풍선으로 “어떤 이름으로 불러줄꺼양?” 하고 묻고, 바로 아래 한 줄에서 이름이나 별명(1~24자)을 입력하고 `확인`. 카메라는 붉은 양을 말풍선 바로 위에 세웁니다. 이때는 서버에 추첨 요청을 보내지 않습니다.
3. **소망 + 복주머니** — 복주머니가 떨어지고 붉은 양이 말풍선으로 “내년에 가장 바라는 1순위 소망은 뭐야?” 하고 물으면, 말풍선 아래 8가지(건강·사랑·성공·여행·성장·쉼·새출발·함께) 중 하나를 고르면 주머니가 흔들리다 터집니다. 서버는 그 소망에 어울리는 곡·덕담 묶음(`src/data/hopes.ts`) 안에서 각각 균등 추첨합니다(`POST /api/draw` 본문의 `hope`).
4. **결과** — 붉은 양이 말풍선으로 “짜잔! {이름}의 새해 첫 곡이 나왔양.” 하고, 그 아래 결과 카드에 소망·곡·아티스트·덕담, `첫 곡 듣기`(YouTube 모달), `티켓 저장`(PNG), `친구에게 공유`, 테스트 모드의 `다른 소망 고르기`(다시 고르면 직전 곡·덕담은 제외). 상단 `처음부터`는 초원으로 돌아가며 이름과 결과는 그대로 남습니다.
5. **친구에게 공유** — 보내는 사람(선택, 12자)과 메시지(선택, 100자)를 적고 `공유하기`(휴대폰 공유 시트: 카카오톡·메시지 등) 또는 `링크 복사`. 친구는 `/s` 페이지에서 보낸 사람·메시지·소망·곡·덕담을 보고 바로 듣거나 자기 첫 곡을 받으러 갈 수 있습니다.

### 공유 링크와 개인정보

`/s?s=<곡>&b=<덕담>&h=<소망>#n=<메모>` 형태입니다. 쿼리에는 곡·덕담 번호와 소망 키만 들어가고, 보내는 사람과 메시지는 `#` 뒤(URL 조각)에 base64url로 담깁니다. 브라우저는 `#` 뒤를 서버로 보내지 않으므로 서버 로그에 남지 않고, 따로 저장하는 곳도 없습니다. 입력한 이름은 링크에 자동으로 넣지 않습니다(보내는 사람 칸은 직접 적는 경우에만 담김). 링크 미리보기 제목에는 곡 제목이 들어가며, 미리보기 이미지는 `NEXT_PUBLIC_SITE_URL` 또는 Vercel 프로덕션 도메인을 기준으로 만들어집니다.

## 실행

Node.js 20.9 이상(개발·검증은 Node 24에서 했습니다).

```bash
npm install
npm run dev        # http://localhost:3027 (개발 서버)
npm run typecheck  # next typegen + tsc --noEmit
npm test           # vitest: 추첨·기간 경계·API·저장·티켓 레이아웃·인트로/카메라·스프라이트·양떼
npm run build
npm start          # http://localhost:3027 (프로덕션 서버)
```

처음 실행하면 **테스트 모드**라서 날짜와 상관없이 바로 참여하고 여러 번 다시 뽑을 수 있습니다.

## 테스트 / 정식 모드 전환

`.env.example`을 `.env.local`로 복사해 `EVENT_MODE`를 바꾼 뒤 서버를 다시 시작합니다. 값이 없거나 `live`가 아니면 항상 `test`입니다.

| 값 | 동작 |
|---|---|
| `EVENT_MODE=test` (기본) | 언제든 열림. 다시 뽑기는 직전 곡·덕담을 각각 제외합니다. |
| `EVENT_MODE=live` | 2027-01-01 00:00 ~ 2027-01-02 00:00 **한국시간**(UTC 2026-12-31T15:00Z ~ 2027-01-01T15:00Z)에만 열림. 그 전은 대기, 이후는 마감. 같은 브라우저에서는 처음 받은 곡·덕담을 다시 보여 줍니다. |

PowerShell에서 한 번만 정식 모드로 띄우려면:

```powershell
$env:EVENT_MODE='live'; npm start
```

모드는 서버에서만 읽고 `GET /api/event` 응답으로 화면에 전달됩니다. 정식 모드의 “1회”는 같은 브라우저 저장소 기준 UX이며 로그인·IP·기기 간 동기화는 하지 않습니다.

## 곡·덕담 수정

- 소망: `src/data/hopes.ts` — 소망마다 어울리는 곡·덕담의 인덱스 목록. 모든 곡과 덕담이 적어도 한 소망에 들어 있어야 합니다(테스트가 확인).
- 곡: `src/data/songs.ts` — `{ title, artist, videoId }`. `videoId`는 YouTube 영상 ID 11자(대소문자·밑줄·하이픈 그대로).
- 덕담: `src/data/blessings.ts`.

배열 길이는 코드에서 읽으므로 개수를 바꿔도 됩니다. 다만 브라우저에는 “인덱스 + 영상 ID”로 마지막 결과가 저장되므로, **순서를 바꾸거나 영상 ID를 바꾸면 이전에 저장된 결과는 자동으로 폐기**됩니다. 수정 후 `npm test`의 데이터 검사(개수·ID 중복·형식)를 함께 고쳐 주세요.

## 도트 그림 고치기

지형·캐릭터는 “아트 픽셀” 단위의 작은 캔버스에 그린 뒤 확대해 픽셀 경계를 유지하고, 하늘·햇무리·스포트라이트는 화면 해상도로 부드럽게 그립니다. 해에서 뻗어 나가는 햇살 줄무늬는 욱일기처럼 보일 수 있어 넣지 않습니다(해는 언덕 뒤에 반쯤 걸린 그라데이션 원 + 구름 띠). 스프라이트는 `src/game/sprites.ts`의 문자열 격자(`.`=투명, 나머지는 팔레트 키)라서 글자만 바꿔 수정할 수 있습니다. 색은 같은 파일의 팔레트와 `src/game/world.ts`의 새벽/일출 색 쌍에서 바꿉니다.

## 참고

- 음악은 사용자가 ‘첫 곡 듣기’를 누를 때만 YouTube 임베드가 생성됩니다. 일부 영상은 지역·권리 설정으로 임베드가 막힐 수 있어 모달에 원문 링크가 항상 있습니다. YouTube 광고가 나올 수 있습니다.
- 픽셀 글꼴은 [Galmuri](https://github.com/quiple/galmuri)(SIL OFL 1.1)를 프로젝트에 포함했습니다. 12px 격자 글꼴이라 18·24·36·48px처럼 6의 배수 크기에서 가장 또렷합니다.
